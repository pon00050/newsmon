Windows: portable app (no installation)

  1. Download newsmon-{{version}}-windows-portable.zip from the latest release, under Assets.
  2. Extract it to a folder you own. Do not run it from inside the zip viewer.
  3. Double-click Newsmon\Newsmon.exe. A console window opens, the server starts on this computer only, and your browser opens http://127.0.0.1:8765/. Close the window or press Ctrl+C to stop.
  4. Choose what to monitor by editing %LOCALAPPDATA%\Newsmon\config\sources.yaml and profiles\. Settings and data stay there when you update or move the program.

The build is not code-signed, so Windows SmartScreen may show "Windows protected your PC": choose More info, then Run anyway. Check the zip first against SHA256SUMS.txt from the same release (PowerShell: Get-FileHash .\newsmon-{{version}}-windows-portable.zip).

Windows: double-click launcher from the source archive

  1. Download newsmon-{{version}}-source.zip and extract it. Paths with spaces are fine.
  2. Double-click Start-Newsmon.cmd. On first use it offers to install uv for your account (no administrator rights), then downloads Python and the libraries once, which takes a few minutes. Later starts take seconds.

Neither option needs an AI key or an account.

From source (any system)

Requires uv. uv selects a suitable Python (3.12 or newer) automatically.

git clone {{repo_url}}.git
cd newsmon
uv sync --frozen
uv run newsmon init
uv run newsmon serve --auto-collect

Then open the address the command prints. Run uv run newsmon --help to list every command. The example configuration is in config.example/.

Verify what you downloaded

  • Download only from the releases page of the repository linked in this site's footer.
  • Compare checksums when the release notes list them.
  • Prefer the source install if you want to read the code first.
