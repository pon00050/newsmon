Newsmon

A local news-monitoring tool for foreign-news desks. It collects from sources you are licensed to use, removes duplicates, ranks what is left with rules you control, and gives you a searchable queue on your own computer.

Download See the dashboard Source on GitHub

The problem

A foreign-news desk reads many feeds and wire services in several languages. The same event arrives from five sources within minutes, the important item is buried among routine ones, and each licence limits what you may keep, show or send to an AI service. Newsmon turns that stream into one ranked queue and keeps the licence terms attached to each source, so the rules travel with the data.

What it does

Collects

Licensed RSS and Atom feeds, plus wire files dropped into an inbox folder. Only the sources you list are fetched.

Normalises

Different feed shapes become one record: source, language, published time, headline, link, and body where the licence allows it.

Deduplicates

Near-identical items from different sources collapse into one entry that shows how many duplicates it absorbed.

Ranks by your rules

A profile of configurable rules places each item in a band: flash, report, review or drop.

Searchable local queue

A web page served only on your own machine. Search in Korean, Chinese and English, filter by band, language, source and time window, and see why each item was ranked as it was.

Optional AI enrichment

Off unless enabled, and gated by the licence of each source. Items whose licence does not allow it are not sent.

Windows launcher

Double-click to set up, start the queue and open your browser. No command line needed.

The public dashboard

The dashboard shows what a run of Newsmon produces. The synthetic dataset is invented to demonstrate the interface. A live dataset, when published, contains only headlines and links from sources whose public redistribution is documented, and each source's basis is linked next to its items.

Limitations

  • Newsmon is a monitoring and triage aid. It does not replace editorial judgement, and ranking is only as good as the profile rules you write.
  • It collects only from sources you configure. It does not discover feeds, scrape pages or bypass paywalls.
  • Licence handling is a safeguard, not legal advice. You are responsible for confirming that your agreements allow what you configure.
  • It runs on one machine for one desk. It is not a hosted service and has no multi-user accounts.
  • The one-click launcher is for Windows. On other systems, run it from source.
